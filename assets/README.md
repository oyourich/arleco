# Исходные изображения

Добавлять только согласованные фотографии и графические материалы.

Рекомендуемая структура:
- `projects/` — фотографии реализованных объектов
- `material/` — макросъёмка древесины и производство
- `brand/` — логотип и графические элементы

До получения исходников вместо изображений используются нейтральные заглушки.

Не загружать клиентские материалы, требующие конфиденциальности, в публичный репозиторий.
