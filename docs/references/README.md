## Правила работы с референсами

1. Не приписывать проекту визуальные решения, если страница или скриншоты не были просмотрены.
2. Разделять подтверждённые наблюдения, пользовательские комментарии и собственные гипотезы.
3. Сохранять оригинальную ссылку и по возможности добавлять скриншоты/кадры, чтобы референс оставался полезным при недоступности внешней страницы.
4. Извлекать конкретные приёмы, а не копировать чужой сайт целиком.
5. Референсы не отменяют утверждённые решения АРЛЕКО. Приоритет исходников, указаний пользователя и актуальных границ проекта — в [AGENTS.md](../../AGENTS.md).
