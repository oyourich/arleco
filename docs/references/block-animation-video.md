# Видео-референс: анимация блоков и секций

- Источник: https://www.youtube.com/watch?v=0wyES5u_tUA
- Формат: YouTube-видео.
- Добавлено: 2026-11-25.
- Проект применения: АРЛЕКО.
- Назначение: посмотреть варианты анимации блоков сайта и переходов между секциями.

## Статус
Видео добавлено в библиотеку по запросу пользователя. Сам ролик пока не удалось открыть для просмотра, поэтому конкретные приёмы и таймкоды не зафиксированы.

## Что изучить при просмотре
- Появление и выход контента внутри секции.
- Переходы между соседними блоками: склейки, маски, раскрытия, смена масштаба.
- Поведение крупных фотографий и архитектурных объектов при скролле.
- Связь движения типографики с изображением.
- Параллакс и глубина слоёв: амплитуда, скорость, направление.
- Темп, длительность, паузы и точки фиксации композиции.
- Как анимации ведут себя при обратном скролле и на мобильном экране.

## Правила применения в АРЛЕКО
- Не переносить эффекты автоматически: сначала определить, какую задачу решает каждый приём.
- Сохранять читаемость архитектурных фотографий и заголовков; один доминирующий движущийся акцент за раз.
- Не менять утверждённый лоадер, хиро и существующие блоки без отдельного запроса.
- После просмотра дополнить документ конкретными наблюдениями и таймкодами. Не записывать предположения как факты.
