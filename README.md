# АРЛЕКО — сайт компании

Проект лендинга производителя деревянных домов из карельской сухостойной сосны.

## Задача
Создать выразительный, понятный сайт с акцентом на архитектуру, натуральную древесину, реальные объекты и полный цикл работ.

## Структура первой итерации
1. Главный экран
2. Каталог / направления
3. Материал и технология
4. Реализованные проекты

Дальнейшие разделы: строительство под ключ, комплектации и ориентиры стоимости, компания, контакты. Калькулятор и 3D-конфигуратор — возможные последующие этапы.

## Файлы
- `index.html` — прототип страницы
- `styles.css` — стили и адаптивная сетка
- `docs/project-brief.md` — вводные и принципы дизайна
- `assets/README.md` — правила для исходных изображений

## Запуск
Открыть `index.html` в браузере. Сборка и зависимости пока не требуются.

> Изображения, проекты и стоимость должны быть согласованы с заказчиком. Текущие текстовые блоки — рабочие формулировки.

## Дизайн-стратегия (рабочий проект)

[Открыть проект дизайн-стратегии](docs/design-strategy/README.md) — развиваем позиционирование, эмоциональный язык и презентационную подачу АРЛЕКО. Сохраняем исследовательские повороты, сомнения и принципы для будущего дизайнерского кейса. **Это не утверждённое ТЗ на изменение сайта.**
